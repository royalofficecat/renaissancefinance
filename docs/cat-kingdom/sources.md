# Sources and licences — “What if domestic cats took over California?”

This is a **fictional scenario**. The story (the takeover, the council, the economy, the "reign" timeline) is invented and is labelled fictional on screen.
**Every real-world fact or number in a caption or stats panel** traces to a row in **Facts** below.

## Facts

How these were checked: each figure was cross-checked against the agency, university or paper below through web search. This machine's network blocks direct downloads from most of those sites, so the quotes come from search excerpts of the primary pages. **Open each link once before publishing.** C3 (an estimate) and C6 (a pre-pandemic count) are the two to read most carefully.
